# 📦 CRUD Inventory Prototype (FastAPI)

This project is a **prototype inventory management system** built with **FastAPI**.  
It was created as part of my learning journey with FastAPI, focusing on building and understanding **CRUD (Create, Read, Update, Delete)** operations for managing inventory items.

---

## 🚀 Features
- ➕ Add new inventory items  
- 📋 View all items  
- ✏️ Update existing items  
- ❌ Delete items  
- ⚡ Powered by **FastAPI** for quick development and testing  

---

## 🛠️ Tech Stack
- **FastAPI** → Web framework  
- **Pydantic** → Data validation  
- **SQLite / In-memory DB** (optional) → Simple storage layer  
- **Uvicorn** → ASGI server  

---

## 📂 Project Status
This is a **learning prototype**, not a production-ready app.  
The goal was to practice **FastAPI fundamentals** and explore how to build CRUD APIs.
